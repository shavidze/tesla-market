# Style Guide — ვიზუალური ენა

## ხელწერა ერთი წინადადებით

Braun-ის კატალოგი ქართულად: მკაცრი grid, პატარა ფუნქციური ლეიბლები (ქართული, tracking-ის გარეშე), დიდი ჰაერი,
პროდუქტის ფოტო გმირად, წითელი მხოლოდ იქ, სადაც ფულია (ფასი) და მოქმედება (დარეკვა).

## ხელმოწერის ელემენტები (რითაც გვცნობენ)

1. **ლოგო** (2026-11-05-დან) — მანქანის კონტური + `teslamarket.ge` წარწერა, მუქი ლურჯი.
   ფაილები: `public/logo.webp` (header, თეთრ ფონზე), `public/logo-white.webp` (ფუტერი, მუქ ფონზე),
   ფავიკონები მხოლოდ მანქანით (`favicon.ico`, `favicon-32/192.png`, `apple-touch-icon.png`), `og.png`.
   ლოგოს ფერები მხოლოდ ლოგოს ეკუთვნის — UI token-ებში არ გადადის (accent ისევ წითელია).
   ძველი წითელი „ნაკლული ნაწილის" ნიშანი (`docs/brand/`) საარქივოა.
2. **ნაწილის ბარათი № -ით** — ჩარჩოში ჩასმული სპეცი, head-ში `№ {id}`, როგორც საწყობის
   იარლიყზე. იგივე ფორმა (`Spec.ts`) მეორდება მაღაზიის ბარათზე მთავარსა და კონტაქტზე.
3. **„საკარნახო" mono** — ნაწილის № და OEM სისტემურ monospace-ში: მყიდველი მაშინვე ხედავს,
   რა უნდა თქვას ზარისას.
4. **ფოტო-თარო** — ყველა ნაწილი თეთრ, ჰაერიან ჩარჩოში; მეორე ფოტო — მისი ეტიკეტი.
5. **მიკრო-ლეიბლი** — `microLabelClass`, tracking-ის გარეშე. სექციების, მეტა-ინფოს,
   ფუნქციური წარწერების ერთადერთი ფორმა.
6. **კონტრასტული ბლოკი** — ერთი მუქი (`bg-ink`) სექცია გვერდზე (ამჟამად: ფუტერი).

ყოფილი exploded-view hero ილუსტრაცია (ძრავი/კბილანები — ელექტრომობილს არ აქვს) ამოღებულია; ფაილი `public/hero.png` საარქივოდ რჩება.

რეფერენსების მეთოდი და შესადარებელი პროექტები: [`../design-direction-2026-10-31.md`](../design-direction-2026-10-31.md).

## ლეიაუტი

- **სექციური ბანდინგი (Apple-ის რიტმი):** გვერდი შრეებად — თეთრი ↔ `bg-bg` (#F5F5F7) მონაცვლეობით, ბოლოს ერთი მუქი ბლოკი (ფუტერი). ბანდი full-width არის, შიგთავსი — კონტეინერში. თითო ბანდი = შინაარსის ტიპის ცვლა (სტრუქტურა ინფორმაციაა).
- **კონტეინერი:** `max-w-6xl mx-auto px-4` — ყველგან, გამონაკლისის გარეშე.
- **ვერტიკალური რიტმი:** სექციები `py-12 md:py-16`; hero `py-12 md:py-16` grid-ით.
- **Grid-ები:** პროდუქტები `grid-cols-2 md:grid-cols-4`; კატეგორიები `grid-cols-2 sm:grid-cols-3 md:grid-cols-6`.
- **სწორება:** ტექსტი მარცხნივ (Swiss). ცენტრირება მხოლოდ ცარიელ მდგომარეობებში.
- **Borders, არა shadows.** სიღრმე კონტრასტით და სივრცით გამოიხატება, არა ჩრდილით.

## ფოტოგრაფია (პროდუქტები)

1. **ფონი:** თეთრი ან ძალიან ღია, ერთფეროვანი (ფურცელი ან დაფა). ნაწილი ცალკეა, მანქანაზე დამაგრებული არა.
2. **კადრი:** კვადრატი (1:1), ნაწილი კადრის ~70–80%, ცენტრში, ჩრდილი რბილი.
3. **ფოტო #1:** მთლიანი ნაწილი პირდაპირ — ბარათზე ეს ჩანს.
4. **ფოტო #2:** ეტიკეტი/OEM სტიკერი ახლოდან, თუ აქვს.
5. **ფოტო #3+:** სამაგრები, კონექტორები და **ყოველი დაზიანება ახლოდან** (Rams #5).
6. **აკრძალულია:** სხვა საიტის/კატალოგის ფოტო, AI-გენერაცია, ფილტრები, წყლის ნიშნები.

ჩვენებისას ფოტო არ იჭრება (`object-contain`), თეთრ ჩარჩოშია padding-ით.

## ტექსტის ხმა

- ქართული, საქმიანი და თბილი. არა ჟარგონი, არა გადაჭარბება („საუკეთესო", „უნიკალური" — არა).
- მოქმედების ღილაკი ამბობს რას აკეთებს: „დარეკვა", „შენახვა", „კატალოგის ნახვა".
- მდგომარეობა ყოველთვის ფაქტობრივი: „ახალი" / „მეორადი" — შელამაზების გარეშე.
- არა ყალბი urgency: ტაიმერები, „ბოლო ცალია", ფიქტიური ფასდაკლებები — აკრძალულია.
- ტერმინოლოგია ერთიანი: მეორადი (არა „used"), მარაგი, მიღება მაღაზიაში.
- შეცდომები კონკრეტული და მშვიდი: „ტელეფონის ნომერი არასწორია" (არა „უი, რაღაც აირია").

## რა არასდროს ვაკეთებთ

- მესამე ფერი ეკრანზე · gradient · ჩრდილი · მრგვალი „bubble" ესთეტიკა
- დეკორატიული აიქონები ფუნქციის გარეშე · კარუსელები · popup-ები
- ანიმაცია საიტზე (მოძრაობა მხოლოდ hover/focus მიკრო-გადასვლებია: `transition-colors`)
