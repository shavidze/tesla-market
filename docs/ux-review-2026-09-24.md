# TeslaMarket — UX შეფასება

შეფასება ეყრდნობა მიმდინარე გვერდებს, მობილურის ეკრანებსა და პროექტის დიზაინის ფილოსოფიას. მიზანი: მოდელი → ნაწილი → თავსებადობის გარკვევა → დაკავშირება.

## შესრულება

მფლობელის თანხმობით განხორციელდა კომპაქტური ფილტრები და ძიების ცარიელი შედეგის გამოსწორების გზა; ფოტოების არჩევა და სრული ზომით ახალ ჩანართში გახსნა; თავსებადობის მონაცემებისა და ფასის აღწერამდე ჩვენება; პროდუქტის კოდი და Maps ბმული; მობილური ადმინის ბარათები; სტატუსის შენახვის დადასტურება/შეცდომა; არასრული ჩანაწერების მინიშნებები; გვერდის მისამართის დამატებით დეტალებში გადატანა. პროდუქტების ფოტოები აღარ იჭრება ჩვენებისას.

მარაგის ნამდვილობა, ფასები და ნაწილების ნამდვილი ფოტოები მფლობელისგან დასადასტურებელია. არსებული ჩანაწერები არ წაშლილა და ინტერნეტში ნაპოვნი მანქანის ფოტოები ნაწილების ფოტოებად არ გამოქვეყნებულა. ნულოვანი რაოდენობა სტატუსს ავტომატურად არ ცვლის. ქვემოთ შენარჩუნებულია შეფასების პრიორიტეტები და საჭირო ბიზნეს მონაცემები.

## ფოტოები

მოდელების ბარათებისთვის შერჩეულია Wikimedia Commons-ის ნამდვილი ფოტოები. თითოეული არის CC BY-SA 4.0 ლიცენზიით; ავტორისა და წყაროს ბმულები მთავარ გვერდზეა. გამოყენებულია 960px ასლები, დამატებითი კადრირების ან გენერაციული ცვლილების გარეშე. Model S-ის წყარო უკვე კადრირებული ვერსიაა; Model 3-ის წყაროზე სიკაშკაშეა შესწორებული — ეს ცვლილებები მითითებულია ავტორებთან.

მოდელის ფოტო მხოლოდ ნავიგაციას ემსახურება და კონკრეტული წლის ნაწილთან თავსებადობას არ ადასტურებს. პროდუქტის ფოტოდ სხვა მანქანის ან სხვისი ნაწილის ფოტო არ უნდა იქნეს წარმოდგენილი.

## გაზომვა

შემდეგი ეტაპის ცვლილებები შეფასდეს მობილურზე ნაწილის პოვნის სიმარტივით, ძებნის უშედეგო შედეგებითა და პროდუქტიდან დაკავშირების მოქმედებებით. კონვერსიის ზრდა წინასწარ გარანტირებული არ არის. ანალიტიკის ახალი სისტემა ამ შეფასების ფარგლებში არ დამატებულა.
